The use of generative networks to synthesize MRI images in areas marked by controlled data masking

I tested and modified 3 GANs (HDN, MD-GAN, CoModGAN) and tested how they work with image inpainting. 
I tested different masks, starting with 8% and ending with 80% of the image. 

I choose best working model to generate real MRI images on the places where was the mask.
To show the effects of the model I programmed an app, where the user can apply the mask to the image by themselves.
